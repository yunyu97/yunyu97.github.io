3. Precision lab: why naive formulas fail at TeV energies

Each quantity is computed live as naive float32, naive float64 and stable float64, and compared with an 80-digit reference (decimal.js). The beam energy follows the √s slider above. At 10 TeV the muon mass is only 10−5 of the energy.

Relative error colours: < 1e-12, < 1e-6, worse; an error of 1 means no correct digit. The reference is computed from the same double-precision inputs, converted via their shortest decimal representation, so the stable results show ~1e-16 from input rounding alone. Float32 is emulated with Math.fround after every operation.

Scope and honest limits

Tree level, fixed couplings, massless final-state fermions, unpolarised beams, no ISR or beam-energy spread; quark channels are leading order. Neutrino fluxes are the primary neutrinos from beam-muon decay; hadronic secondaries are not modelled. Pythia 8 has no s–t interference for μμ→μμ, so that comparison covers the t-channel only. The surrogate is slower than the closed form it emulates, so no speed-up is claimed. AI-versus-human development time has not been measured. The report analyst shown in the Python tool is rule-based by default. The JavaScript on this page is a re-implementation of the Python formulas for display; the Python package is the reference.
