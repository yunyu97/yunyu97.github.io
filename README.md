# yunyu97.github.io

Personal homepage, served by GitHub Pages at https://yunyu97.github.io.

Everything is in `index.html` (plain HTML/CSS, no build step). Text shown with a yellow
highlight (`class="todo"`) is placeholder content — replace it and remove the `todo` class.
Delete the yellow note at the top of `<main>` once everything is filled in.

- **CV PDF:** add `cv.pdf` to this folder and point the "Download full CV" button at it.
- **Professor Cat downloads** link to the newest release of
  [professor-cat-desktop-pet](https://github.com/yunyu97/professor-cat-desktop-pet/releases), so uploading
  a new release with the same file names updates the buttons automatically.
